# Limitations and research validity

**Important:** This repository runs *hypothetical experiments* using synthetic companies.
It is educational and exploratory, not an investment, legal, regulatory or public-policy tool.

| Claim | Status |
|---|---|
| The code executes a configured event-based simulation | Supported by the shipped source and automated tests |
| Outputs are reproducible under the same input and seed | Tested on synthetic cases |
| The event engine can represent buyer withdrawal, legal appeals, technical incidents | Tested representations, not observed frequencies |
| 63 cases in offline documentary Atlas | Research background; dataset not included in public repo |
| Estimated probability of a real corporate restructuring succeeding | **Not established** |
| Historical calibration of full operational independence | **Not established** |
| Benefit to market competition, employment, consumers or welfare | **Not modeled** |

Synthetic outcomes depend on the assumed rules and are **not statistically independent
measurements of real economic activity**. Sample rates cannot be used as economic forecasts.
The `V3.2.1-I03` label refers to the internal motor and extensions; this public presentation
has only the tests and datasets included with it.
